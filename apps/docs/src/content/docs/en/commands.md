---
title: Chat commands
description: Chat commands for the streamer and mods.
---

The streamer and mods can control Vigia from chat. Every command works in English and Spanish.

| Command | In Spanish | What it does |
|---|---|---|
| `!vigia pause` · `resume` | `pausa` · `sigue` | Stops and restarts moderation; highlights continue |
| `!vigia status` | `estado` | Shows the rules, pause and observe state |
| `!vigia progress "Chapter 3"` | `progreso` | Sets your progress for the anti-spoiler |
| `!vigia rule <id> on` · `off` | `regla` | Turns a rule on or off |
| `!vigia highlight [text]` | `destaca` | Puts a text, or the message you reply to, on stream |
| `!vigia clear` | `limpia` | Clears the overlay |
